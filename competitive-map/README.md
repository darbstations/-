# الخريطة التنافسية لمحطات درب — مكة المكرمة

دراسة موقعية لخمس محطات، مبنية على ملف الإحداثيات المرفق.

## المخرجات

| الملف | الوصف |
|---|---|
| `index.html` | تقرير تفاعلي مستقل بالكامل (خريطة SVG، نطاقات خدمة، مصفوفة مسافات، بطاقات تحليل). يفتح مباشرة في المتصفح بلا إنترنت. |
| `darb-competitive-map-makkah.xlsx` | مصنّف من ٦ أوراق: المحطات · مصفوفة المسافات · ٣ جداول حصر · المنهجية. |
| `geo.json` | مخرجات الحساب الجغرافي (مسافات، اتجاهات، نسب تداخل). |

## أبرز النتائج

- **تجمّع شرقي متداخل**: `MK019` عرفات الشرائع و`MK023` بن درويش و`MK002` المعيصم
  ضمن دائرة قطرها ~٣ كم. أقصر مسافة **١٫٥٨ كم** (MK019↔MK023)، وتداخل نطاق الخدمة
  عند ٣ كم يبلغ **٦٦٫٩٪** بينهما و**٥٦٫٨٪** مع المعيصم.
- **موقعان منفردان بلا منافسة داخلية**: `MK007` العمرة الجديدة و`MK017` عرفات الشوقية
  (أقرب محطة على بعد ١٥٫٣٥ و١٤٫٨٥ كم على الترتيب).
- `MK017` هو الأقرب للحرم (**٥٫٩٧ كم**)، و`MK002` الأقرب للمشاعر (منى **٥٫٨٧ كم**).

## حالة الحصر الميداني — غير مكتمل

جداول المنشآت المحيطة (تأجير السيارات، مكاتب الحج والعمرة، الشركات الحكومية والخاصة)
**فارغة عمداً**. تعذّر سحب البيانات لسببين تقنيين:

1. حساب Apify تجاوز الحد الشهري للاستخدام (*Monthly usage hard limit exceeded*).
2. نطاق `overpass-api.de` (بيانات OpenStreetMap) محجوب بسياسة شبكة الجلسة (403).

لم تُدرَج أي أسماء منشآت أو إحداثيات تقديرية بدلاً من البيانات الحقيقية.

## إكمال الحصر

```bash
export APIFY_TOKEN=xxxxxxxx          # بعد رفع الحد من console.apify.com/billing
python3 collect_pois.py              # يبحث ٥ كم حول كل محطة ← pois.json
python3 build_workbook.py            # يملأ جداول الإكسل
python3 build_report.py              # يملأ جداول التقرير التفاعلي
```

`collect_pois.py` يبحث بخمسة مصطلحات حول كل محطة (محطة وقود · تأجير سيارات ·
حج وعمرة · شركة · حكومي)، يرشّح النتائج ضمن نصف قطر ٥ كم فعلي، يزيل التكرار،
ويحسب المسافة والاتجاه لكل منشأة.

## إعادة بناء التحليل الجغرافي

```bash
python3 build_geo.py                 # يعيد حساب geo.json من الإحداثيات
```
