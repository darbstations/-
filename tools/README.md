# أدوات بناء تقرير المحطات الخمس

## الملف المعتمد

`darb-five-stations-analysis.html` في جذر المستودع هو **النسخة المعتمدة**،
وقد اعتمدها المستخدم بعد أن عدّل عليها بنفسه: حذف أقسامًا من صفحات الخطة
التشغيلية، وأضاف صفوفًا عبر نماذج الإدخال.

**لا تُعاد سلسلة التوليد كاملة على هذا الملف** — إعادة التشغيل من
`build_five_stations.py` تعيد بناء المحتوى من الصفر وتمسح تعديلات المستخدم.
كل إضافة جديدة تُطبَّق **فوق الملف المعتمد** بسكربت مستقل يعدّل ما يخصّه فقط،
ويُتحقق منه بمقارنة سطرية قبل/بعد تُثبت أن ما تغيّر هو المقصود وحده.

مثال — سكربت يقبل مسار مصدر ومخرَج:

```bash
python3 tools/add_month_reasons.py <ملف-المصدر> [ملف-المخرَج]
```

## السلسلة التاريخية

بُني الملف أصلًا بهذا الترتيب، وتُحفظ السكربتات للرجوع والتوثيق لا للتشغيل
الدوري:

| # | السكربت | ما يضيفه |
|---|---|---|
| 1 | `build_five_stations.py` | تقليص التقرير إلى خمس محطات + طبقة التحرير |
| 2 | `add_liters.py` | اللترات بجانب كل رقم بالريال |
| 3 | `format_liters_kpi.py` | سطر اللترات في بطاقات المؤشرات |
| 4 | `add_cs_pages.py` | تبويب استفسارات العملاء |
| 5 | `add_partner_dayparts.py` | تبويب الشركاء عبر اليوم (٦ فترات) |
| 6 | `add_page_builder.py` | السحب والإفلات وإضافة الأقسام والجداول |
| 7 | `add_month_cards.py` | بطاقة تحليل لكل شهر |
| 8 | `add_targets_tab.py` | تبويب المستهدفات |
| 9 | `add_external_tab.py` · `fill_external_tab.py` | تبويب الشركاء الخارجيين + تراجع/إعادة |
| 10 | `add_ops_plan.py` | تبويب الخطة التشغيلية |
| 11 | `add_plan_forms.py` | نماذج إدخال الحملات والشراكات والتوزيعات |
| 12 | `make_fully_editable.py` | تعديل كل شيء: أعمدة · تسميات · تبويبات |
| 13 | `add_month_reasons.py` | سبب كل شهر من تقرير التحليل التفصيلي |

`apify_nearby_partners.py` مستقل عن السلسلة: يستخرج المنشآت حول المحطات عبر
Apify عند توفّر رصيد في الحساب.
