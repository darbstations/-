# إحداثيات محطات درب — Station Coordinates

استخراج إحداثيات (خط العرض / خط الطول) لجميع المحطات من جدول **Station Data**، بحلّ روابط خرائط Google المختصرة (`maps.app.goo.gl`) الموجودة في عمود Location إلى مواقعها الفعلية.

## النتيجة

| البند | العدد |
|---|---|
| إجمالي المحطات في الجدول | 219 |
| محطات استُخرجت إحداثياتها | **216** |
| — من أماكن مسجّلة في خرائط Google (Place) | 138 |
| — من دبابيس إحداثيات مُشارَكة مباشرة (Pin) | 78 |
| محطات بدون رابط لوكيشن أصلاً في الجدول | 3 (MK038 محطة القديرة، MK334 صناعية الطائف، AS359 المصيف خميس مشيط) |
| صفوف عليها تنبيهات تحتاج مراجعة | 18 |

## الملفات

- **`stations_with_coordinates.xlsx`** — الملف الرئيسي: ورقة البيانات + ورقة «ملاحظات المنهجية». الصفوف المظللة بالأصفر عليها تنبيهات، وبالبرتقالي بدون إحداثيات.
- **`stations_with_coordinates.csv`** — نفس البيانات بصيغة CSV (ترميز UTF-8 with BOM يفتح مباشرة في Excel).
- **`stations_with_coordinates.json`** — نفس البيانات بصيغة JSON للاستخدام البرمجي.
- **`stations.geojson`** — نقاط جاهزة للعرض على أي خريطة (Google My Maps, Mapbox, QGIS...).

## الأعمدة

| العمود | الوصف |
|---|---|
| `row` | رقم الصف في الجدول الأصلي |
| `station_number` | رقم المحطة (MK001…) |
| `city` | المدينة كما في الجدول |
| `station_name` | اسم المحطة كما في الجدول |
| `operational_status` | Operation / Franchises |
| `latitude`, `longitude` | الإحداثيات المستخرجة (WGS84) |
| `coords_source` | `google_place` = مكان مسجّل في Google؛ `dropped_pin` = دبوس إحداثيات من الرابط نفسه |
| `google_place_name`, `google_address` | اسم وعنوان المكان في خرائط Google (للأماكن المسجّلة فقط) |
| `place_id` | معرّف المكان في Google (للأماكن المسجّلة) |
| `original_short_url` | الرابط المختصر كما ورد في الجدول |
| `google_maps_link` | رابط مباشر للإحداثيات المستخرجة |
| `notes` | تنبيهات الجودة (روابط مكررة، بُعد عن المدينة المذكورة، اختلاف رابط الخلية عن نصها...) |

## المنهجية

1. قُرئ جدول Station Data (بما فيه الروابط المضمّنة داخل الخلايا، وليس النص الظاهر فقط).
2. حُلّ كل رابط مختصر إلى رابطه النهائي الكامل بتتبّع تحويلات HTTP.
3. الأماكن المسجّلة في Google أُخذت إحداثياتها من بيانات المكان نفسه، والدبابيس أُخذت إحداثياتها من معاملات الرابط النهائي (`q=lat,lng` أو `!3d…!4d…`).
4. فحوص جودة: روابط مستخدمة لمحطتين مختلفتين (AS255/AS124 و RY355/RY356)، صفوف نصّ الخلية فيها يختلف عن الرابط المضمّن (10 صفوف)، وإحداثيات تبعد كثيرًا عن المدينة المذكورة (18 صفًا — مفصّلة في عمود notes وورقة الملاحظات).
